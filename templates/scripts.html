How AutoFlow works
  • Every script in {{ folder }} becomes one video, in name order. A made script is skipped next time.
  • A script is a .md, .txt, PDF or Word (.docx) file. Names starting with "_" (the template) are left out.
  • A folder is one video: its script from a "Scripts" folder inside it (the .md first, when it's there as a PDF too), and the pictures in its "Character" folder, used for that video only.
  • A script laid out in CLIP 1, CLIP 2… (or SCENE 1, SCENE 2…) goes to Flow as written, one 8-second clip each; any other is split into clips by Gemini.
  • Each video gets the Flow form's defaults: by hand, no review, Check each clip off, Auto style, language and genre, 9:16 unless the script says 16:9.
  • After a stop, press Try again on that video, then Start: Start alone makes the script again as a new video.
